# Базовые техники тест-дизайна

Использовать этот каталог как стартовую карту при анализе задачи. Подробные карточки добавляются по шаблону `technique-card.md`.

| Техника | Когда полезна | Пример применения |
|---|---|---|
| Классы эквивалентности | Есть группы входов с одинаковым ожидаемым поведением | Типы пользователей, форматы номера телефона |
| Граничные значения | Ошибки вероятны на границах диапазона | Минимальная и максимальная сумма |
| Decision table | Результат зависит от комбинации условий | Роли, статусы и права доступа |
| State transition | Объект проходит через состояния | Заказ, платеж, заявка |
| Pairwise | Много параметров и комбинаций | Браузер, ОС, тариф, регион |
| Use case testing | Важны реальные пользовательские потоки | Регистрация и оформление заказа |
| Error guessing | Известны слабые места или исторические дефекты | Повторная отправка формы, таймаут |
| Exploratory testing | Требования неполные или поведение новое | Быстрое исследование нового экрана |

При выборе техники AI должен объяснить связь между техникой и конкретным риском, а не перечислять техники формально.
